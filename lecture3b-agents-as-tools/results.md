For this assignment, I started by taking my original taboo topic from the jailbreaking lecture and applying it to the guardrails. At first, I experimented with a predetermined workflow of input guardrail -> main chatbot -> output guardrail, but I also experimented with giving the output guardrail the ability to call chat as a tool when the output was wrong. This had the advantage of having the agent try again only when necessary, but I found that the guardrail chatbot didn't always do the best job of re-prompting the chatbot, so it could sometimes take awhile for the output guardrail to finish and the responses could be pretty long as well. One of my takeaways from this assignment was that guardrails can be really useful, but you still need to be thoughtful about the architecture of the system and how you choose to implement the guardrails to be most effective.
