For this homework, I tried making a workflow that used multiple agents to find general conference talks based on a paraphrase, as we did earlier in the semester. Originally, I had found that using web search was fairly effective at this compared to my own attempts to scrape the data, but I wanted to see if I could improve the results. I used different agents to accomplish this, including one that parsed the user's query for the speaker, keywords, etc. Another one checked to see if more information was needed, and if so, ask the user follow up questions. Others were used to find the speaker's general conference page and parse through talks, with a final agent used to summarize the results. This process was definitely slower than some of the previous implementations, which makes sense since there were so many more steps. However, the results felt more trustworthy, consistent, and reliable. The summary in particular was significantly improved, returning several possible matches rather than just one in addition to providing the link, speaker, and other important information. I think that splitting it up allowed for each bot to do its job well, rather than hoping that a single agent would do a good job on every step of the process. After I initially got everything working, I also experimented with having the program delegate the search of multiple talks across multiple concurrent agents so that more ground could be covered simultaneously and avoid overloading context for any one agent. I think it helped the processing to go a little bit faster for queries which required going through many talks. Overall, I definitely think the search was more effective than the previous iterations, at the expense of cost and speed.
