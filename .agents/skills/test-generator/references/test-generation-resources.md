# Test Generation Resource Checklist

Use this checklist to gather missing context before generating or revising tests.

## Required Inputs

- Code snippet or path to the target function/module.
- Programming language and test framework (for example `pytest`, `unittest`, `jest`, `vitest`).

## Helpful Context

- Related project files or collaborating modules.
- Project style expectations for naming, structure, and formatting.
- Coverage expectations, including normal and edge-case priorities.

## Fallback Rule

If framework or style is unclear, infer from existing tests in the same repository area and follow that pattern.
