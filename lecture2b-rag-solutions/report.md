After configuring my environment and making sure that I could get chromadb to work on my computer, I experimented with a few different aspects of using RAG and answering questions about General Conference talks. First, I didn't want my chatbot to always use RAG no matter the query, since actual chatbots must be selective when they use RAG or not. To accomplish this, I implemented a secondary chatbot which took in the user prompt and decided whether or not the question was related to general conference or topics that might be discussed in it. If it was, then I would have it search in ChromaDB, but it would respond normally if not. I also wanted to make the embedding more effective in cases where the user's prompt by itself would not be very effective for the purposes of embedding, so I also had an AI model rewrite the prompt for embedding purposes, which improved the performance of the chatbot. During the process, I also learned more about how to use AI roles (i.e., system vs. user vs. assistant) because I noticed that simply embedding the extra information from the database made the model think that the user was providing the information, rather than assuming that it was the one gathering the information and then providing it to the user. I don't think I got this aspect quite perfect, but I definitely learned a lot about how chatbot construction works.
