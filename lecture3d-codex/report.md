For this assignment, I downloaded Codex, learned about how to use it, and used it to create a simple Connect 4 app. I was pretty impressed with how it did. It set up a functioning application (on localhost) within just a couple minutes, including implementing the logic, styling, and even some animations. All it needed was a few clarifications on requirements from me, and then it was off and running. I noticed that it preferred to keep it simple with vanilla HTML, CSS, and JavaScript rather than using frameworks like React. It does a pretty good job by default, but it requires a little bit more steering to nail things that you want done very specifically. 

I also played around with the skill-creator a little bit. It wasn't super intuitive, but I was able to figure it out by reading through the documentation. It seemed like AI itself wasn't totally sure exactly how it was supposed to be implemented, which I'm sure will be improved upon in the future.
